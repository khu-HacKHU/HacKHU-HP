# 갤러리 사용자 스토리

본 문서는 갤러리에서 누가 무엇을 할 수 있는지와 완료 조건을 정한다.

역할의 정의는 제품 명세를 따른다. ([PRODUCT.md](../PRODUCT.md))

<br>

### 1. 앨범 보기

누구나 앨범 목록과 앨범 안의 사진을 본다.

| 상황 | 기대 |
|---|---|
| 로그인하지 않은 방문자가 갤러리를 엶 | 앨범 목록과 사진을 볼 수 있음 |
| 앨범 목록 | 앨범마다 제목, 활동 날짜와 대표 사진이 보임 <br> 활동 날짜가 최근인 앨범이 먼저 옴 |

<br>

### 2. 앨범 올리기

동아리원은 제목, 활동 날짜와 사진을 묶어 앨범을 올린다.

| 항목 | 값 |
|---|---|
| 앨범 하나의 사진 수 | 1장 이상 20장 이하 |
| 허용 형식 | jpg, png, webp |
| 사진 하나의 최대 크기 | 10MB |
| 올리는 사람 | 동아리원 |

| 상황 | 기대 |
|---|---|
| 로그인하지 않은 방문자나 승인 대기 회원이 올리려 함 | 올리기 버튼이 보이지 않음 <br> 다른 방법으로 시도해도 막힘 |
| 허용하지 않는 형식을 고름 | 올라가지 않고 허용 형식이 안내됨 |
| 10MB를 넘는 사진을 고름 | 올라가지 않고 크기 제한이 안내됨 |
| 21장 이상을 고름 | 올라가지 않음 |
| 사진 없이 올리려 함 | 올라가지 않음 |

앨범의 첫 번째 사진이 대표 사진이다.

<br>

### 3. 앨범 삭제

앨범을 올린 사람이나 관리자는 앨범을 지운다. 앨범을 지우면 안의 사진도 함께 지워진다.

| 상황 | 기대 |
|---|---|
| 다른 사람이 올린 앨범을 지우려 함 | 관리자가 아니면 지울 수 없음 |
| 앨범을 지움 | 앨범과 사진이 목록에서 사라지고 사진 주소로도 볼 수 없음 |

앨범 안의 사진은 한 장씩 지우지 않는다. 앨범을 수정하지 않는다는 범위와 같다. ([배경](BACKGROUND.md))
