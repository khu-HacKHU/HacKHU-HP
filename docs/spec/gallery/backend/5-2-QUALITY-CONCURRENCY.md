# 5-2 동시성

본 문서는 갤러리 백엔드의 동시 요청, 중복 처리, 잠금과 순서 보장을 정한다.

<br>

### 5-2-1 조회 주소 서명 비용

앨범 목록과 상세는 사진마다 CloudFront 서명을 한 번씩 계산한다. 서명은 서버 안의 RSA 연산이라 외부 호출은 없지만, 목록 `size`가 최대 100이라 한 요청에 서명이 100번까지 늘 수 있다.

| 항목 | 값 |
|---|---|
| 서명 한 번 | RSA-2048 기준 1~2ms 정도 |
| 한 요청의 최대 서명 수 | 100 (목록 `size` 상한) |
| 지금 쓰는 크기 | 갤러리 목록 20, 메인 화면 4 |

지금은 캐시를 두지 않는다. 느려지면 `CloudFrontPhotoUrlResolver`에서 객체 키와 만료 구간을 키로 서명 결과를 캐시한다. 만료가 1시간이라 캐시가 잘 맞는 구조다.
