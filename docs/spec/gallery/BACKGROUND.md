# 갤러리 배경

본 문서는 갤러리 기능이 왜 필요한지와 범위를 정한다.

<br>

### 1. 왜 필요한가

갤러리는 동아리 활동 사진을 외부 방문자와 동아리원에게 보여 주는 곳이다. 활동을 외부에 알리는 것이 목적이므로 로그인하지 않아도 본다.

활동 사진은 행사마다 여러 장이 생긴다. 사진을 한 장씩 올리면 목록이 금방 어지러워지므로 행사 단위의 앨범으로 묶어 올린다.

<br>

### 2. 범위

- 앨범 목록과 앨범 안의 사진 조회
- 앨범 올리기와 삭제
- 파일 업로드에 쓰는 presigned URL 발급. 자료게시판 첨부도 같은 방식을 쓴다. 형식과 크기는 각 기능의 사용자 스토리가 정한다.

<br>

### 3. 범위 밖

- 앨범과 사진은 수정하지 않는다. 바꾸려면 지우고 다시 올린다.
- 메인 화면에 보이는 최근 앨범은 홈 기능에서 다룬다. ([홈](../home/AGENTS.md))
