# 홈 사용자 스토리

본 문서는 메인 화면과 동아리 소개에서 누가 무엇을 볼 수 있는지와 완료 조건을 정한다.

역할의 정의는 제품 명세를 따른다. ([PRODUCT.md](../PRODUCT.md))

<br>

### 1. 메인 화면

누구나 메인 화면을 본다. 메인 화면은 동아리를 한 줄로 소개하고, 최근 공지와 최근 앨범을 보여 주고, 가입이나 로그인으로 안내한다.

| 영역 | 보이는 것 |
|---|---|
| 동아리 소개 | 동아리 이름과 한 줄 소개 <br> 동아리 소개 화면으로 가는 링크 |
| 최근 공지 | 최신 공지 5개의 제목과 작성일 <br> 누르면 그 공지로 이동함 <br> 공지 전체 목록으로 가는 링크 |
| 최근 앨범 | 활동 날짜가 최근인 앨범 4개의 제목, 활동 날짜, 대표 사진 <br> 누르면 그 앨범으로 이동함 <br> 갤러리로 가는 링크 |
| 안내 | 로그인하지 않은 방문자에게 가입하기와 로그인 링크가 보임 |

| 상황 | 기대 |
|---|---|
| 로그인하지 않은 방문자가 메인 화면을 엶 | 위 네 영역이 모두 보임 |
| 공지나 앨범이 하나도 없음 | 그 영역에 아직 글이나 앨범이 없다는 안내가 보임 |
| 공지나 앨범을 불러오지 못함 | 그 영역에만 불러오지 못했다는 안내가 보이고 나머지 영역은 그대로 보임 |
| 승인 대기 회원이 메인 화면을 엶 | 승인을 기다린다는 안내가 보임 |
| 동아리원이 메인 화면을 엶 | 가입하기와 로그인 링크가 보이지 않음 |

- 자유게시판과 자료게시판의 글은 메인 화면에 보여 주지 않는다. 동아리원만 볼 수 있는 글이라 로그인하지 않은 방문자에게 보이면 안 되기 때문이다.
- 공지와 앨범의 내용, 권한은 게시판과 갤러리의 사용자 스토리를 따른다. ([board/USER-STORIES.md](../board/USER-STORIES.md), [gallery/USER-STORIES.md](../gallery/USER-STORIES.md))

### 2. 동아리 소개

누구나 동아리 소개 화면을 본다. HacKHU가 어떤 동아리이고 무엇을 하는지 알린다.

| 영역 | 보이는 것 |
|---|---|
| 소개 | 경희대학교 최초의 정보보안 동아리라는 소개와, 전공, 학년, 경험과 관계없이 보안에 관심 있는 사람을 환영한다는 문구 |
| 활동 | 매주 정기 스터디(보안 기초부터 함께 학습) <br> 팀 프로젝트(CTF 출제, 버그 바운티 같은 실전 경험) <br> 연합 CTF(다른 대학 동아리와 교류전) |
| 문의 | 동아리에 연락하는 방법 |

| 상황 | 기대 |
|---|---|
| 로그인하지 않은 방문자가 소개 화면을 엶 | 소개, 활동, 문의가 모두 보임 |
| 소개 문구를 바꾸고 싶음 | 화면에서 고칠 수 없음 <br> 운영진이 홈페이지 담당자에게 요청해 바꿈 |

- 문의에는 개인 휴대전화 번호를 넣지 않는다. 홈페이지는 누구나 볼 수 있어서 번호가 수집될 수 있기 때문이다. 동아리 공용 연락처를 쓴다.
- 동아리 공용 연락처(이메일이나 SNS 계정)는 미정이다.
- 신입부원 모집 기간에 지원서 링크를 소개 화면에 둘지는 미정이다. 홈페이지 가입과 동아리 지원은 다른 절차라 둘을 혼동하지 않게 안내해야 한다.
