# 홈 사용자 스토리

본 문서는 메인 화면과 동아리 소개에서 누가 무엇을 볼 수 있는지와 완료 조건을 정한다.

<br>

### 1. 메인 화면

누구나 메인 화면을 본다. 메인 화면은 동아리를 한 줄로 소개하고, 최근 공지와 최근 앨범을 보여 준다.

| 영역 | 보여 주는 것 |
|---|---|
| 소개 한 줄 | 동아리 이름과 한 줄 소개, 동아리 소개 화면으로 가는 링크 |
| 최근 공지 | 최신 공지 5개의 제목과 날짜 <br> 누르면 그 공지로 감 |
| 최근 앨범 | 최신 앨범 4개의 대표 사진, 제목, 활동 날짜 <br> 누르면 그 앨범으로 감 |

| 상황 | 기대 |
|---|---|
| 로그인하지 않은 방문자가 메인 화면을 엶 | 세 영역이 모두 보임 |
| 공지나 앨범이 하나도 없음 | 그 영역에 빈 목록 안내가 보임 |
| 최근 공지나 최근 앨범을 불러오지 못함 | 그 영역에만 오류 안내가 보이고 나머지 영역은 보임 |

자유게시판과 자료게시판의 글은 메인 화면에 보여 주지 않는다. 동아리원 전용 글이기 때문이다.

<br>

### 2. 동아리 소개

누구나 동아리 소개를 본다. 소개는 운영진이 화면에서 고치지 않고 코드로 관리하는 고정된 화면이다.

| 영역 | 보여 주는 것 |
|---|---|
| 동아리 소개 | HacKHU가 어떤 동아리인지 |
| 활동 | 정기 활동과 스터디 |
| 운영진과 연락처 | 문의할 곳 |

소개 문구, 활동 목록과 연락처는 동아리장의 의견을 받아 정한다.
