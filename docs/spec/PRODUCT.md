# 제품

본 문서는 HacKHU 홈페이지 전체에 걸치는 사실을 정한다.

제품 정의, MVP 범위와 하지 않는 것, 역할, 기능과 담당 팀, 공통 용어를 정리한다. 기능별 배경과 사용자 스토리는 각 기능 폴더에 있다.

<br>

### 1. 제품 정의

HacKHU 홈페이지는 경희대학교 보안 동아리 HacKHU의 공식 홈페이지다. 외부 방문자에게 동아리 소개, 공지와 활동 사진을 보여 주고, 동아리원에게는 자유게시판과 자료게시판을 제공한다. 운영진은 공지를 올리고 가입을 승인한다.

이 홈페이지는 교육형 프로젝트로 만든다. 참가자는 기능을 개발하면서 보안 도구를 CI/CD 파이프라인에 붙이고, 라운드마다 도구 결과를 판별하고, 완성된 기능을 직접 공격하고 고친다. 참가자 대부분의 목적은 개발보다 이 과정을 경험하는 데 있다. 일정과 보안 라운드는 레포 README에 있다. ([README](../../README.md))

<br>

### 2. MVP 범위

S5 운영 배포 때 아래 기능이 모두 동작해야 한다.

| 기능 | 포함하는 것 |
|---|---|
| 인증권한 | 이메일과 비밀번호로 가입, 로그인과 로그아웃, 가입 승인과 거절, 역할 변경, 내 정보(비밀번호 변경, 탈퇴), 비밀번호 초기화 |
| 게시판 | 공지, 자유게시판, 자료게시판의 글 작성, 조회, 수정, 삭제 <br> 자료게시판 첨부파일 |
| 갤러리 | 앨범과 사진의 업로드, 조회, 삭제 |
| 홈 | 메인 화면, 동아리 소개 |

<br>

### 3. 하지 않는 것

| 하지 않는 것 | 이유 |
|---|---|
| 댓글, 검색, 마크다운 에디터, 알림, 워게임 | MVP에 넣지 않음 <br> S4에 여유가 있는 팀만 확장으로 다루고, 취약점 학습 가치 순으로 고름 |
| 메일 발송 | 메일 발송 인프라(AWS SES, 도메인 인증)가 인프라팀의 일을 크게 늘림 <br> 그래서 학교 이메일 인증과 비밀번호 재설정 메일도 하지 않음 |
| GitHub 로그인 | 필요 없다고 판단함 |
| Google 로그인 | MVP에 넣지 않음 <br> MVP 뒤에 추가 기능으로 다룸 |
| 서비스 분리(MSA) | 인원과 기간에 비해 운영 부담이 큼 <br> 백엔드 하나, 프론트엔드 하나로 배포함 |

<br>

### 4. 역할

| 역할 | 누구인가 |
|---|---|
| GUEST | 로그인하지 않은 방문자 |
| PENDING | 가입했지만 운영진의 승인을 기다리는 사람 |
| MEMBER | 승인을 받은 동아리원 |
| STAFF | 운영진 |
| ADMIN | 관리자 <br> 역할을 바꿀 수 있음 |

- 역할은 GUEST, PENDING, MEMBER, STAFF, ADMIN 순으로 높다. "MEMBER 이상"은 MEMBER, STAFF, ADMIN을 뜻한다.
- PENDING은 로그인할 수 있지만 쓸 수 있는 기능은 GUEST와 같다.
- 첫 ADMIN은 PM과 PL이다. 지정 방식은 인증권한팀이 정한다. ([5-1 보안](auth/backend/5-1-QUALITY-SECURITY.md))
- 가입, 승인, 역할 변경의 흐름은 인증권한 기능에서 정한다. ([인증권한 사용자 스토리](auth/USER-STORIES.md))
- 기능별로 누가 무엇을 할 수 있는지는 각 기능의 사용자 스토리가 정한다.
- 인증(누구인가)은 인증권한 기능이 맡는다. 인가(무엇을 할 수 있는가)는 각 기능이 자기 범위에서 직접 검사한다.

### 6. 공통 용어

| 용어 | 뜻 |
|---|---|
| 동아리원 | MEMBER 역할인 사람 |
| 운영진 | STAFF 역할인 사람 |
| 관리자 | ADMIN 역할인 사람 |
| 승인 대기 | PENDING 역할인 상태 |
| 공지 | 운영진이 쓰고 누구나 보는 게시판 |
| 자유게시판 | 동아리원이 쓰고 동아리원만 보는 게시판 |
| 자료게시판 | 동아리원이 첨부파일과 함께 자료를 공유하는 게시판 <br> 동아리원만 봄 |
| 첨부파일 | 자료게시판 글에 붙이는 파일 |
| 앨범 | 활동 사진을 행사 단위로 묶은 갤러리의 게시 단위 |
| presigned URL | S3에 파일을 직접 올리거나 받도록 서버가 발급하는 만료 시간이 있는 주소 |
