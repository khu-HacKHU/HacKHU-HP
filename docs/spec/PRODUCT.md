# 제품

본 문서는 HacKHU 홈페이지 전체에 걸치는 사실을 정한다.

제품 정의, 첫 버전 범위와 하지 않는 것, 역할, 기능과 담당 팀, 공통 용어를 정리한다. 기능별 배경과 사용자 스토리는 각 기능 폴더에 있다.

<br>

### 1. 제품 정의

HacKHU 홈페이지는 경희대학교 보안 동아리 HacKHU의 공식 홈페이지다. 외부 방문자에게 동아리 소개, 공지와 활동 사진을 보여 주고, 동아리원에게는 자유게시판과 자료게시판을 제공한다. 운영진은 공지를 올리고 가입을 승인한다.

이 홈페이지는 동아리원이 직접 만든다. 만드는 동안 보안 점검 도구로 자기 코드를 검사하고, 완성된 기능을 직접 공격해 보고 고치는 것이 이 프로젝트의 목적이다.

<br>

### 2. 첫 버전 범위

첫 버전(MVP)은 홈페이지를 처음 공개할 때 갖출 기능이다.

| 기능 | 포함하는 것 |
|---|---|
| 인증권한 | 이메일과 비밀번호로 가입, 로그인과 로그아웃, 가입 승인과 거절, 역할 변경, 내 정보(비밀번호 변경, 탈퇴), 비밀번호 초기화 |
| 게시판 | 공지, 자유게시판, 자료게시판의 글 작성, 조회, 수정, 삭제 <br> 자료게시판 첨부파일 |
| 갤러리 | 앨범과 사진의 업로드, 조회, 삭제 |
| 홈 | 메인 화면, 동아리 소개 |

<br>

### 3. 하지 않는 것

| 하지 않는 것 | 이유 |
|---|---|
| 댓글, 검색, 글 꾸미기 에디터, 알림, 워게임 | 첫 버전에 넣지 않음 <br> 첫 버전을 마친 뒤 여유가 있으면 추가함 |
| 메일 발송 | 메일을 보내려면 발송 설비와 도메인 인증을 따로 갖춰야 해서 일이 크게 늚 <br> 그래서 학교 이메일 인증과 비밀번호 재설정 메일도 하지 않음 |
| Google 로그인 | 첫 버전에 넣지 않음 <br> 첫 버전 뒤에 추가 기능으로 다룸 |

<br>

### 4. 역할

| 역할 | 누구인가 |
|---|---|
| 방문자 | 로그인하지 않은 사람 |
| 승인 대기 회원 | 가입했지만 아직 운영진의 승인을 받지 않은 사람 |
| 동아리원 | 운영진의 승인을 받은 사람 |
| 운영진 | 동아리를 운영하는 사람 <br> 공지를 쓰고 가입을 승인함 |
| 관리자 | 운영진 가운데 다른 사람의 역할을 바꿀 수 있는 사람 |

- 역할은 방문자, 승인 대기 회원, 동아리원, 운영진, 관리자 순으로 높다. 높은 역할은 낮은 역할이 할 수 있는 일을 모두 할 수 있다. 그래서 이 명세에서 "동아리원"은 운영진과 관리자를 포함하고, "운영진"은 관리자를 포함한다.
- 승인 대기 회원은 로그인할 수 있지만 방문자가 할 수 있는 일만 할 수 있다.
- 처음 관리자는 PM과 PL이다.
- 기능별로 누가 무엇을 할 수 있는지는 각 기능의 사용자 스토리에 있다.

### 6. 공통 용어

| 용어 | 뜻 |
|---|---|
| 공지 | 운영진이 쓰고 누구나 보는 게시판 |
| 자유게시판 | 동아리원이 쓰고 동아리원만 보는 게시판 |
| 자료게시판 | 동아리원이 첨부파일과 함께 자료를 공유하는 게시판 <br> 동아리원만 봄 |
| 첨부파일 | 자료게시판 글에 붙이는 파일 |
| 앨범 | 활동 사진을 행사 단위로 묶은 갤러리의 게시 단위 |
