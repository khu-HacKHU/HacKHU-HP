# UI 디자인 시스템

본 문서는 홈페이지의 모든 화면이 같이 쓰는 색, 글꼴, 간격, 공용 컴포넌트, 공통 헤더와 메뉴를 정한다.

기능별 화면 배치는 각 기능의 `frontend/2-2-LAYOUT.md`에서 정하고 여기서 정한 값을 가져다 쓴다. 값을 새로 만들어야 하면 화면에 바로 넣지 말고 이 문서에 먼저 추가한다.

<br>

### 1. 방향

터미널을 닮은 어두운 남보라색 화면이다. 색은 HacKHU 로고와 신입부원 모집 포스터에서 가져왔다. 글꼴, 간격, 셸 프롬프트 표현은 동아리장 개인 사이트([danielcho02.github.io](https://danielcho02.github.io))를 따른다. 두 자료에 없는 폼, 표, 버튼 같은 컴포넌트는 OpenCode와 Warp의 디자인 분석을 참고해 같은 색으로 맞췄다. ([9. 참고](#9-참고))

| 원칙 | 내용 |
|---|---|
| 어두운 화면 하나만 | 밝은 테마는 두지 않음 |
| 선으로 나눔 | 영역은 1px 선과 패널 배경으로만 나눔 <br> 카드에 그림자를 쓰지 않음 |
| 빛 효과는 메인 화면에만 | 로고의 은은한 빛 번짐, 배경의 보라색 번짐과 옅은 격자는 메인 화면에서만 씀 <br> 게시판, 갤러리, 폼 화면 배경은 단색 |
| 포인트 색은 아껴 씀 | 화면 대부분은 배경, 글자, 선 세 가지 색 <br> 라일락색은 주요 동작과 로고에만 씀 |
| 터미널 문구는 메인 화면에만 | 셸 프롬프트 제목과 ASCII 로고는 메인 화면에서만 씀 <br> 게시판, 갤러리, 폼 화면은 평범한 한국어 제목을 씀 (5절) |

<br>

### 2. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `bg` | `#0f1022` | 페이지 배경, 입력창 배경 |
| `panel` | `#181a33` | 카드, 폼, 안내 상자 배경 <br> 표 행 호버 배경 |
| `line` | `#2c2e4d` | 영역 구분선, 표 행 구분선, 카드 테두리 |
| `line-strong` | `#676a96` | 입력창, 버튼 테두리 <br> 배경과 3:1 이상이 되도록 `line`보다 밝게 둠 |
| `ink` | `#ece8f4` | 본문 글자 |
| `muted` | `#a4a3bf` | 보조 글자, 날짜, 번호, 표 머리글 |
| `lilac` | `#e0bfe6` | 로고 글자색 <br> 주요 버튼 배경, 포커스 테두리, 선택된 페이지 번호 |
| `on-lilac` | `#1a1030` | 라일락색 배경 위 글자 |
| `violet` | `#c58cf2` | 본문 속 강조 글자, 링크 호버 <br> 운영진, 관리자 배지 |
| `cyan` | `#5cc8e8` | 섹션 이름표(6-7절), 셸 프롬프트의 사용자 이름 <br> 성공, 완료 상태 |
| `coral` | `#f0727a` | 오류, 삭제 버튼, 경고 안내 |

- `lilac`은 동아리 GitHub 아이콘의 글자색(`#e0bfe6`)이다. `bg`와 `panel`은 아이콘 배경의 남보라색을 어둡게 맞춘 값이다.
- `violet`, `cyan`은 모집 포스터의 강조 글자와 섹션 이름표 색에 맞춘 값이다. 포스터 원본 파일에서 뽑은 값이 아니라 눈으로 맞춘 값이라, 원본 파일을 받으면 다시 맞춘다.
- 위 색 밖의 원색(초록, 노랑 등)을 새로 들이지 않는다.
- 상태를 색으로만 알리지 않는다. 오류는 `coral`과 함께 문구를, 선택된 항목은 `lilac`과 함께 테두리나 굵기를 같이 쓴다.

명도 대비 (WCAG AA 기준은 본문 4.5:1, 입력창 테두리 3:1)

| 조합 | `bg` 위 | `panel` 위 |
|---|---|---|
| `ink` 글자 | 15.6:1 | 14.1:1 |
| `muted` 글자 | 7.7:1 | 6.9:1 |
| `lilac` 글자 | 11.4:1 | 10.3:1 |
| `violet` 글자 | 7.5:1 | 6.8:1 |
| `cyan` 글자 | 9.7:1 | 8.8:1 |
| `coral` 글자 | 6.6:1 | 6.0:1 |
| `line-strong` 테두리 | 3.7:1 | 3.3:1 |
| `lilac` 배경 위 `on-lilac` 글자 | 11.0:1 | |

`line`(1.4:1)은 장식용 구분선에만 쓰고, 입력창처럼 모양을 알아봐야 하는 테두리에는 `line-strong`을 쓴다.

<br>

### 3. 글꼴과 크기

| 이름 | 글꼴 | 쓰는 곳 |
|---|---|---|
| `sans` | IBM Plex Sans KR | 본문, 제목, 버튼, 입력창 |
| `mono` | IBM Plex Mono (한글은 IBM Plex Sans KR로 대체) | 날짜, 글 번호, 배지, 표 머리글, 셸 프롬프트, 코드 |

두 글꼴 모두 SIL Open Font License라 홈페이지에 포함해 배포할 수 있다.

| 이름 | 크기 | 쓰는 곳 |
|---|---|---|
| `text-xs` | 0.8rem | 날짜, 배지, 도움말 |
| `text-sm` | 0.875rem | 메뉴, 보조 문구, 버튼 |
| `text-base` | 1.0625rem | 본문 |
| `text-lg` | 1.33rem | 화면 제목, 카드 제목 |
| `text-xl` | 1.66rem | 섹션 큰 제목 |
| `text-2xl` | 2.3rem | 메인 화면 첫 제목 |

- 본문 줄 간격은 1.7, 제목은 1.3이다.
- 굵기는 400(본문), 500(버튼, 표 머리글), 600(제목), 700(메인 첫 제목)만 쓴다.
- 한국어 줄바꿈은 단어 단위로 한다(`word-break: keep-all`).

<br>

### 4. 간격과 모양

| 이름 | 값 |
|---|---|
| 간격 | `space-1` 0.25rem, `space-2` 0.5rem, `space-3` 0.75rem, `space-4` 1rem, `space-6` 1.5rem, `space-8` 2rem, `space-12` 3rem, `space-16` 4rem, `space-24` 6rem <br> 이 9개 밖의 이름(`space-5`, `space-10` 등)은 없음 |
| `radius` | 6px (카드, 버튼, 입력창) <br> 배지와 페이지 번호는 4px |
| `measure` | 68ch (긴 글 본문 최대 폭) |
| 페이지 최대 폭 | 76rem, 좌우 여백 1.5rem |

- 간격은 위 단계에서만 고른다. 13px, 22px처럼 단계에 없는 값을 쓰지 않는다.
- 화면 폭이 760px보다 좁으면 두 칸 배치는 한 칸으로, 표 형태 목록은 줄 단위로 바뀐다.

<br>

### 5. 터미널 표현

메인 화면에서만 쓴다.

| 표현 | 예 | 규칙 |
|---|---|---|
| 셸 프롬프트 제목 | `guest@hackhu:~$ ls -lt ~/notice` | 사용자 이름은 `cyan`, `~$`는 `lilac`, 명령은 `ink` <br> 로그인해도 사용자 이름은 `guest`로 둠 (화면 공유나 캡처에 이름이 남지 않게) |
| ASCII 로고 | HacKHU 글자 | `lilac`, `mono` 0.8rem, 은은한 빛 번짐 <br> 좁은 화면에서는 숨김 |
| `ls -l` 형 목록 | `2026-11-05  공지  2학기 정기 세미나 안내` | 날짜, 종류는 `mono`와 `muted` <br> 제목은 `sans` |

게시판, 갤러리, 로그인처럼 기능을 쓰는 화면에는 터미널 문구를 넣지 않는다. 동아리원이 아닌 방문자도 바로 읽을 수 있어야 하기 때문이다. 날짜와 번호를 `mono`로 쓰는 것만 공통이다.

<br>

### 6. 공용 컴포넌트

각 팀은 아래 컴포넌트를 새로 만들지 말고 같이 쓴다. 컴포넌트를 처음 만드는 팀이 공용 위치에 두고, 다른 팀은 가져다 쓴다. 위치와 이름은 `frontend/AGENTS.md`에서 정한다.

### 6-1. 버튼

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 주요 | `lilac` 배경, `on-lilac` 글자 | 화면에서 가장 중요한 동작 하나 (로그인, 저장, 글쓰기) |
| 기본 | 투명 배경, `line-strong` 테두리 | 취소, 목록으로 같은 보조 동작 |
| 위험 | 투명 배경, `coral` 테두리와 글자 | 삭제, 탈퇴, 가입 거절 |
| 비활성 | 원래 모양에 투명도 40% | 조건이 안 맞아 누를 수 없는 버튼 |

- 한 화면에 주요 버튼은 하나만 둔다.
- 기본 버튼에 마우스를 올리면 테두리와 글자가 `lilac`로 바뀐다.
- 위험 버튼은 누른 뒤 한 번 더 확인한다.

### 6-2. 입력창과 폼

| 상태 | 모양 |
|---|---|
| 기본 | `bg` 배경, `line-strong` 테두리, 모서리 6px |
| 포커스 | `lilac` 테두리와 바깥쪽 라일락색 번짐(투명도 18%) |
| 오류 | `coral` 테두리, 아래에 `coral` 글자로 오류 문구 |
| 비활성 | 투명도 40% |

- 모든 입력창에 화면에 보이는 이름표를 둔다. 안내 문구(placeholder)를 이름표 대신 쓰지 않는다.
- 로그인, 가입, 비밀번호 변경은 `panel` 배경 카드에 넣고 최대 폭 26rem으로 가운데 둔다.

### 6-3. 안내 상자

| 종류 | 모양 | 예 |
|---|---|---|
| 일반 | `panel` 배경, 왼쪽 3px `lilac` 선 | 승인 대기 안내 |
| 경고 | `panel` 배경, 왼쪽 3px `coral` 선 | 회원 전용 게시판 안내, 삭제 실패 |

### 6-4. 배지

`mono` 0.75rem, 1px 테두리, 모서리 4px, 배경 없음.

| 배지 | 색 |
|---|---|
| 고정 공지 | `lilac` |
| 승인 대기 | `muted` |
| 동아리원 | `cyan` |
| 운영진 | `violet` 테두리와 글자 |
| 관리자 | `violet` 배경, `on-lilac` 글자 (대비 7.2:1) <br> 역할 변경을 부탁할 사람을 알아볼 수 있게 운영진과 다르게 채움 |

### 6-5. 목록과 표

| 컴포넌트 | 규칙 |
|---|---|
| 게시판 표 | 머리글은 `mono`, `muted` <br> 행마다 아래 1px `line` <br> 마우스를 올린 행은 `panel` 배경 <br> 글 번호와 작성일은 `mono`, `muted` |
| 페이지 번호 | `mono`, 지금 페이지는 `lilac` 테두리와 글자 |
| 빈 목록 | 표 자리에 `muted` 글자로 "아직 글이 없습니다" |

### 6-6. 갤러리 앨범 카드

| 항목 | 규칙 |
|---|---|
| 배치 | 최소 폭 14rem으로 채우는 그리드, 간격 1.25rem |
| 카드 | `panel` 배경, 1px `line` 테두리, 모서리 6px <br> 마우스를 올리면 테두리 `lilac` |
| 대표 사진 | 가로세로 4:3, 넘치는 부분은 잘라 냄 |
| 제목 아래 | 활동 날짜와 사진 수를 `mono`, `muted`로 |


### 6-7. 섹션 이름표

화면이나 카드의 제목 위에 붙이는 짧은 영어 이름표다. 모집 포스터의 `APPLY`, `CONTACT`와 같은 표현이다. 모든 화면에서 쓸 수 있다.

| 항목 | 규칙 |
|---|---|
| 글자 | 영어 대문자, `mono` 600, 0.8rem, 글자 간격 0.3em |
| 색 | `cyan` <br> 앞에 지름 0.45rem `cyan` 점 |
| 예 | `BOARD` 위에 자유게시판 제목, `GALLERY` 위에 갤러리 제목 |

이름표만으로 화면을 설명하지 않는다. 바로 아래에 한국어 제목을 둔다.

<br>

### 7. 공통 헤더와 메뉴

모든 화면 위에 같은 헤더를 둔다. 높이 3.5rem, 아래 1px `line`.

| 위치 | 내용 |
|---|---|
| 왼쪽 | HacKHU 로고. 누르면 메인 화면 <br> 로고 이미지 파일을 받기 전까지는 `mono` 600 글자로 쓰고 `HU`만 `lilac` |
| 가운데 | 공지, 자유게시판, 자료게시판, 갤러리, 동아리 소개 |
| 오른쪽 | 로그인 전: 로그인(기본 버튼), 가입하기(주요 버튼) <br> 로그인 후: 이름, 내 정보, 로그아웃 <br> 운영진 이상: 관리 메뉴에 가입 승인 추가 <br> 관리자: 관리 메뉴에 역할 변경 추가 |

- 자유게시판과 자료게시판은 방문자에게도 메뉴에 보이고, 누르면 회원 전용 안내가 나온다.
- 화면 폭이 760px보다 좁으면 가운데 메뉴를 접고 메뉴 버튼으로 연다.
- 페이지 맨 앞에 "본문으로 건너뛰기" 링크를 둔다. 키보드로 처음 탭을 누르면 보인다.
- 지금 있는 메뉴는 `lilac` 글자로 표시한다.

<br>

### 8. 접근성

- 2절 명도 대비를 지킨다. 새 색 조합을 쓰면 대비를 계산해 표에 추가한다.
- 키보드만으로 모든 동작을 할 수 있어야 한다. 포커스를 받은 요소는 요소에서 2px 떨어진 2px `lilac` 테두리로 보인다. 떨어진 틈에 배경색이 보이므로 `lilac` 배경인 주요 버튼에서도 테두리가 구분된다(`bg` 위 11.4:1). 포커스 표시를 지우지 않는다.
- 사진에는 대체 텍스트를 둔다. 앨범 사진은 앨범 제목과 순번으로 채운다.
- 움직이는 효과는 0.14초 안쪽의 색 변화만 쓰고, 사용자가 움직임 줄이기를 켜면 끈다.
