# UI 디자인 시스템

본 문서는 홈페이지의 모든 화면이 같이 쓰는 색, 글꼴, 간격, 공용 컴포넌트, 공통 헤더와 메뉴를 정한다.

기능별 화면 배치는 각 기능의 `frontend/2-2-LAYOUT.md`에서 정하고 여기서 정한 값을 가져다 쓴다. 값을 새로 만들어야 하면 화면에 바로 넣지 말고 이 문서에 먼저 추가한다.

<br>

### 1. 방향

어두운 남보라색 화면 하나로 간다. 색은 HacKHU 로고와 신입부원 모집 포스터에서 가져왔다. 간격과 본문 폭은 동아리장 개인 사이트([danielcho02.github.io](https://danielcho02.github.io))를 따른다. 두 자료에 없는 폼, 표, 버튼 같은 컴포넌트는 OpenCode와 Warp의 디자인 분석을 참고해 같은 색으로 맞췄다. 화면을 한 화면 단위로 끊는 배치, 반응형 글자 크기 사다리, 호버와 입장 동작은 KHUDA 홈페이지와 design-taste-frontend 스킬을 참고했다. ([9. 참고](#9-참고))

| 원칙 | 내용 |
|---|---|
| 어두운 화면 하나만 | 밝은 테마는 두지 않음 |
| 선으로 나눔 | 영역은 1px 선과 패널 배경으로만 나눔 <br> 카드에 그림자를 쓰지 않음 <br> 어두운 화면에서는 검은 그림자가 보이지 않으므로, 두께는 카드 위쪽 1px 하이라이트로 냄 |
| 섹션은 한 화면씩 | 메인 화면과 소개 화면은 섹션 하나가 화면 하나를 차지함 <br> 섹션 사이를 선이나 그림자로 나누지 않고 높이와 여백으로만 나눔 <br> 제목은 섹션 맨 위에 둠 (글이 적은 히어로와 폼 카드만 가운데에 둠) |
| 빛 효과는 메인 화면 히어로에만 | 2절의 네 색을 겹친 빛 번짐, 옅은 격자, 아주 옅은 입자를 씀 <br> 아래로 갈수록 지워 다음 섹션의 단색 배경으로 이어지게 함 <br> 게시판, 갤러리, 소개, 폼 화면 배경은 단색 |
| 포인트 색은 아껴 씀 | 화면 대부분은 배경, 글자, 선 세 가지 색 <br> 라일락색은 주요 동작과 로고에만 씀 |
| 첫 화면은 보는 화면 | 메인 화면 첫 화면은 영문 한 줄, 큰 워드마크, 동작 하나로 둠 <br> 동아리 설명은 소개 화면에 두고 두 화면에 같은 글을 적지 않음 |
| 터미널 표현은 목록에만 | 날짜와 글 번호를 고정폭으로 쓰는 것만 남김 (5절) <br> 모든 화면이 평범한 한국어 제목을 씀 |

### 2. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `bg` | `#0f1022` | 페이지 배경, 입력창 배경 |
| `panel` | `#181a33` | 카드, 폼, 안내 상자 배경 <br> 표 행 호버 배경 |
| `line` | `#2c2e4d` | 영역 구분선, 표 행 구분선, 카드 테두리 |
| `line-strong` | `#676a96` | 입력창, 버튼 테두리 <br> 배경과 3:1 이상이 되도록 `line`보다 밝게 둠 |
| `ink` | `#ece8f4` | 본문 글자 |
| `muted` | `#a4a3bf` | 보조 글자, 날짜, 번호, 표 머리글 |
| `lilac` | `#e0bfe6` | 로고 글자색 <br> 주요 버튼 배경, 포커스 테두리, 선택된 페이지 번호 |
| `on-lilac` | `#1a1030` | 라일락색 배경 위 글자 |
| `violet` | `#c58cf2` | 본문 속 강조 글자, 링크 호버 <br> 운영진, 관리자 배지 |
| `cyan` | `#5cc8e8` | 섹션 이름표(6-7절), 지금 단계 표시 <br> 성공, 완료 상태 |
| `coral` | `#f0727a` | 오류, 삭제 버튼, 경고 안내 |

- `lilac`은 동아리 GitHub 아이콘의 글자색(`#e0bfe6`)이다. `bg`와 `panel`은 아이콘 배경의 남보라색을 어둡게 맞춘 값이다.
- `violet`, `cyan`은 모집 포스터의 강조 글자와 섹션 이름표 색에 맞춘 값이다. 포스터 원본 파일에서 뽑은 값이 아니라 눈으로 맞춘 값이라, 원본 파일을 받으면 다시 맞춘다.
- 위 색 밖의 원색(초록, 노랑 등)을 새로 들이지 않는다.
- 상태를 색으로만 알리지 않는다. 오류는 `coral`과 함께 문구를, 선택된 항목은 `lilac`과 함께 테두리나 굵기를 같이 쓴다.

명도 대비 (WCAG AA 기준은 본문 4.5:1, 입력창 테두리 3:1)

| 조합 | `bg` 위 | `panel` 위 |
|---|---|---|
| `ink` 글자 | 15.6:1 | 14.1:1 |
| `muted` 글자 | 7.7:1 | 6.9:1 |
| `lilac` 글자 | 11.4:1 | 10.3:1 |
| `violet` 글자 | 7.5:1 | 6.8:1 |
| `cyan` 글자 | 9.7:1 | 8.8:1 |
| `coral` 글자 | 6.6:1 | 6.0:1 |
| `line-strong` 테두리 | 3.7:1 | 3.3:1 |
| `lilac` 배경 위 `on-lilac` 글자 | 11.0:1 | |

`line`(1.4:1)은 장식용 구분선에만 쓰고, 입력창처럼 모양을 알아봐야 하는 테두리에는 `line-strong`을 쓴다.

### 3. 글꼴과 크기

| 이름 | 글꼴 | 쓰는 곳 |
|---|---|---|
| `sans` | Pretendard Variable | 본문, 제목, 버튼, 입력창 |
| `display` | Outfit Variable (한글은 Pretendard로 대체) | 영문 이름표(`NOTICE`, `GALLERY`), 큰 영문 워드마크, `SCROLL` |
| `mono` | IBM Plex Mono (한글은 Pretendard로 대체) | 날짜, 글 번호, 배지, 표 머리글, 코드 |

세 글꼴 모두 SIL Open Font License라 홈페이지에 포함해 배포할 수 있다. 외부 CDN을 거치지 않고 번들에 넣는다. Pretendard는 글자 범위별로 쪼갠 파일(dynamic-subset)을 써서 화면에 나온 범위만 받는다. 한글 글꼴을 통째로 받으면 굵기마다 1MB가 넘는다.

고정폭 글꼴에는 한글이 없다. 날짜와 글 번호처럼 숫자만 있는 자리에 `mono`를 쓰고, 한글이 섞인 문장에는 쓰지 않는다.

| 이름 | 크기 | 쓰는 곳 |
|---|---|---|
| `text-xs` | 0.8rem | 날짜, 배지, 도움말, 이름표 |
| `text-sm` | 0.875rem | 메뉴, 보조 문구, 버튼 |
| `text-base` | 1.0625rem | 본문 |
| `text-lg` | 1.2 ~ 1.33rem | 화면 제목, 카드 제목 |
| `text-xl` | 1.4 ~ 1.9rem | 섹션 큰 제목 |
| `text-2xl` | 1.875 ~ 3.25rem | 메인 화면 첫 제목, 닫는 섹션의 큰 글자 |
| 워드마크 | 3 ~ 9rem | 메인 화면 첫 화면의 `HacKHU` |

- 큰 세 단계는 화면 폭에 따라 움직인다(`clamp`). 좁은 화면에서는 작은 값, 넓은 화면에서는 큰 값이다. 고정값으로 두면 좁은 화면에서 제목이 넘치고 넓은 화면에서는 작아 보인다. 이름은 늘리지 않는다.
- 본문 줄 간격은 1.7, 제목은 1.3이다. 히어로 제목과 워드마크처럼 아주 큰 글자는 1.15 아래로 둔다.
- `strong`으로 쓴 카드 제목은 본문 줄 간격을 물려받으므로 1.3을 다시 적는다.
- 큰 제목(`text-xl` 이상)은 자간을 `-0.01em`으로 좁힌다. 워드마크는 `-0.03em`이다.
- 영문 이름표는 대문자에 자간 `0.3em`, `SCROLL`은 `0.25em`을 준다.
- 굵기는 400(본문), 500(버튼, 표 머리글, 메뉴), 600(제목, 이름표), 700(섹션 제목, 메인 첫 제목, 워드마크)만 쓴다.
- 한국어 줄바꿈은 단어 단위로 한다(`word-break: keep-all`).
- 여러 문장으로 이루어진 긴 서술은 문장마다 줄을 바꾼다.

### 4. 간격과 모양

| 이름 | 값 |
|---|---|
| 간격 | `space-1` 0.25rem, `space-2` 0.5rem, `space-3` 0.75rem, `space-4` 1rem, `space-6` 1.5rem, `space-8` 2rem, `space-12` 3rem, `space-16` 4rem, `space-24` 6rem <br> 이 9개 밖의 이름(`space-5`, `space-10` 등)은 없음 |
| `radius` | 6px (폼 카드, 버튼, 입력창, 사진 틀) <br> 배지와 페이지 번호는 4px |
| `radius-card` | 14px (메인 화면과 소개 화면의 카드) |
| `measure` | 68ch (긴 글 본문 최대 폭) |
| 페이지 최대 폭 | 76rem |
| 좌우 여백 | `space-6`(24px) ~ `space-16`(64px). 화면이 넓어지면 같이 넓어짐 |
| 섹션 위아래 여백 | `space-12`(48px) ~ `space-24`(96px) |
| 헤더 높이 | 3.5rem. 섹션 높이를 계산할 때 이 값을 뺌 |

- 간격은 위 단계에서만 고른다. 13px, 22px처럼 단계에 없는 값을 쓰지 않는다.
- 좌우 여백과 섹션 여백은 두 단계 사이를 화면 폭에 따라 움직인다(`clamp`). 그래도 양 끝은 위 단계의 값이다.
- 한 화면을 차지하는 섹션의 높이는 `100svh`로 둔다. 좁은 화면(640px 아래)에서는 내용이 쌓여 길어지므로 높이에 묶지 않는다.
- 화면 폭이 760px보다 좁으면 두 칸 배치는 한 칸으로, 표 형태 목록은 줄 단위로 바뀐다.

### 5. 목록 표현

| 표현 | 예 | 규칙 |
|---|---|---|
| `ls -l` 형 목록 | `2026-11-05  2학기 정기 세미나 안내` | 날짜는 `mono`와 `muted` <br> 제목은 `sans` <br> 메인 화면의 최근 공지에 씀 |

어느 화면에도 터미널 문구를 넣지 않는다. 동아리원이 아닌 방문자도 바로 읽을 수 있어야 하기 때문이다. 날짜와 번호를 `mono`로 쓰는 것만 남긴다.

셸 프롬프트 제목(`guest@hackhu:~$ …`)과 ASCII 로고는 처음에 메인 화면에 뒀다가 뺐다. 동아리를 처음 보는 사람에게 설명이 되지 않고, 첫 화면에서 워드마크와 역할이 겹쳤다. 되살리려면 이 절에 먼저 다시 적는다.

### 6. 공용 컴포넌트

각 팀은 아래 컴포넌트를 새로 만들지 말고 같이 쓴다. 컴포넌트를 처음 만드는 팀이 공용 위치에 두고, 다른 팀은 가져다 쓴다. 위치와 이름은 `frontend/AGENTS.md`에서 정한다.

### 6-1. 버튼

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 주요 | `lilac` 배경, `on-lilac` 글자 | 화면에서 가장 중요한 동작 하나 (로그인, 저장, 글쓰기) |
| 기본 | 투명 배경, `line-strong` 테두리 | 취소, 목록으로 같은 보조 동작 |
| 위험 | 투명 배경, `coral` 테두리와 글자 | 삭제, 탈퇴, 가입 거절 |
| 비활성 | 원래 모양에 투명도 40% | 조건이 안 맞아 누를 수 없는 버튼 |

- 한 화면에 주요 버튼은 하나만 둔다.
- 기본 버튼에 마우스를 올리면 테두리와 글자가 `lilac`로 바뀐다.
- 위험 버튼은 누른 뒤 한 번 더 확인한다.

### 6-2. 입력창과 폼

| 상태 | 모양 |
|---|---|
| 기본 | `bg` 배경, `line-strong` 테두리, 모서리 6px |
| 포커스 | `lilac` 테두리와 바깥쪽 라일락색 번짐(투명도 18%) |
| 오류 | `coral` 테두리, 아래에 `coral` 글자로 오류 문구 |
| 비활성 | 투명도 40% |

- 모든 입력창에 화면에 보이는 이름표를 둔다. 안내 문구(placeholder)를 이름표 대신 쓰지 않는다.
- 로그인, 가입, 비밀번호 변경은 `panel` 배경 카드에 넣고 최대 폭 26rem으로 가운데 둔다.

### 6-3. 안내 상자

| 종류 | 모양 | 예 |
|---|---|---|
| 일반 | `panel` 배경, 왼쪽 3px `lilac` 선 | 승인 대기 안내 |
| 경고 | `panel` 배경, 왼쪽 3px `coral` 선 | 회원 전용 게시판 안내, 삭제 실패 |

### 6-4. 배지

`mono` 0.75rem, 1px 테두리, 모서리 4px, 배경 없음.

| 배지 | 색 |
|---|---|
| 승인 대기 | `muted` |
| 동아리원 | `cyan` |
| 운영진 | `violet` 테두리와 글자 |
| 관리자 | `violet` 배경, `on-lilac` 글자 (대비 7.2:1) <br> 역할 변경을 부탁할 사람을 알아볼 수 있게 운영진과 다르게 채움 |

### 6-5. 목록과 표

| 컴포넌트 | 규칙 |
|---|---|
| 게시판 표 | 머리글은 `mono`, `muted` <br> 행마다 아래 1px `line` <br> 마우스를 올린 행은 `panel` 배경 <br> 글 번호와 작성일은 `mono`, `muted` |
| 페이지 번호 | `mono`, 지금 페이지는 `lilac` 테두리와 글자 |
| 빈 목록 | 표 자리에 `muted` 글자로 "아직 글이 없습니다" |

### 6-7. 섹션 이름표

화면이나 카드의 제목 위에 붙이는 짧은 영어 이름표다. 모집 포스터의 `APPLY`, `CONTACT`와 같은 표현이다. 모든 화면에서 쓸 수 있다.

| 항목 | 규칙 |
|---|---|
| 글자 | 영어 대문자, `mono` 600, 0.8rem, 글자 간격 0.3em |
| 색 | `cyan` <br> 앞에 지름 `space-2` `cyan` 점 |
| 예 | `BOARD` 위에 자유게시판 제목, `GALLERY` 위에 갤러리 제목 |

이름표만으로 화면을 설명하지 않는다. 바로 아래에 한국어 제목을 둔다.

### 7. 공통 헤더와 메뉴

모든 화면 위에 같은 헤더를 둔다. 높이 3.5rem, 아래 1px `line`. 화면 위에 붙어 따라다닌다(`sticky`). 섹션 하나가 한 화면을 차지하므로, 헤더가 섹션의 위쪽 여백을 덮고 지나가야 첫 화면이 정확히 한 화면이 된다.

| 위치 | 내용 |
|---|---|
| 왼쪽 | HacKHU 로고. 누르면 메인 화면 <br> 로고 이미지 파일을 받기 전까지는 `mono` 600 글자로 쓰고 `KHU`만 `lilac` (이름이 Hack과 KHU를 합친 말이라 그 단위로 끊음) |
| 가운데 | 공지, 자유게시판, 자료게시판, 갤러리, 동아리 소개 |
| 오른쪽 | 로그인 전: 로그인(기본 버튼), 가입하기(주요 버튼) <br> 로그인 후: 이름, 역할 배지, 내 정보, 로그아웃 <br> 운영진 이상: 관리 메뉴에 가입 승인, 회원 관리 추가 |

- 자유게시판과 자료게시판은 방문자에게도 메뉴에 보이고, 누르면 회원 전용 안내가 나온다.
- 화면 폭이 760px보다 좁으면 가운데 메뉴와 관리 메뉴를 접고 메뉴 버튼으로 연다. 이름과 역할 배지는 자리가 없어 접는다. 승인 대기 상태는 헤더 아래 안내 띠가 알려 준다.
- 관리 메뉴는 접는 메뉴로 만들지 않고 링크 두 개로 둔다. 항목이 둘뿐이라 접는 비용이 더 크다. 관리자의 역할 변경은 회원 관리 화면 안에 있다.
- 페이지 맨 앞에 "본문으로 건너뛰기" 링크를 둔다. 키보드로 처음 탭을 누르면 보인다.
- 지금 있는 메뉴는 `lilac` 글자로 표시하고 굵기도 함께 올린다. 색만으로 알리지 않는다.
- 메뉴를 펼친 상태에서 Esc를 누르면 접는다.
- 주요 동작은 헤더, 히어로, 닫는 섹션에서 같은 말을 쓴다. 지금은 "가입하기"다.

<br>

### 8. 접근성

- 2절 명도 대비를 지킨다. 새 색 조합을 쓰면 대비를 계산해 표에 추가한다.
- 키보드만으로 모든 동작을 할 수 있어야 한다. 포커스를 받은 요소는 요소에서 2px 떨어진 2px `lilac` 테두리로 보인다. 떨어진 틈에 배경색이 보이므로 `lilac` 배경인 주요 버튼에서도 테두리가 구분된다(`bg` 위 11.4:1). 포커스 표시를 지우지 않는다.
- 사진에는 대체 텍스트를 둔다. 앨범 사진은 앨범 제목과 순번으로 채운다.
- 그림처럼 쓰는 글자(워드마크, `SCROLL`, 이름표 앞의 점)는 화면 읽기 프로그램에서 가린다. 대신 같은 내용을 한국어 글로 들려준다.
- 움직임은 아래 세 가지만 쓴다. 사용자가 움직임 줄이기를 켜면 모두 끈다.

| 움직임 | 어디 | 값 |
|---|---|---|
| 색 변화 | 모든 화면의 버튼, 링크, 표 행 | 0.14초 |
| 들림과 눌림 | 카드는 올리면 2px 올라감, 버튼은 1px 올라가고 누르면 1px 내려감 <br> 사진은 틀 안에서 1.03배까지 커짐 | 0.14 ~ 0.3초 |
| 입장 | 메인 화면 히어로, 소개 화면 히어로, 폼 카드가 열릴 때 한 번 <br> 투명도와 12px 올라오기 | 0.52초 |

- 스크롤에 따라 움직이는 효과는 쓰지 않는다. 입장은 열릴 때 한 번뿐이다.
