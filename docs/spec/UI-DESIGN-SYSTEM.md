# UI 디자인 시스템

본 문서는 인증권한, 게시판, 갤러리, 홈이 같이 쓰는 화면 규칙을 정한다.

색, 글꼴, 간격, 공용 컴포넌트, 공통 헤더와 전체 메뉴 구조를 정리한다. 기능별 화면 배치는 각 기능의 `frontend/2-2-LAYOUT.md`에서 정하고, 여기서 정한 값을 참조한다. 스타일을 구현하는 방식(CSS 도구)은 레포의 `frontend/AGENTS.md`에서 정한다.

<br>

### 1. 색

동아리 OT 자료와 교육 자료에 쓰인 보라 계열을 대표 색으로 쓴다.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| primary | `#6C4CF1` | 주요 버튼, 링크, 선택된 메뉴 |
| primary-strong | `#5536D6` | primary 위에 마우스를 올렸을 때 |
| accent | `#B13BFF` | 강조 표시, 배지 |
| text | `#1A1A2E` | 본문 글자 |
| text-muted | `#5C5F73` | 보조 글자, 날짜 |
| border | `#E2E4EC` | 구분선, 입력창 테두리 |
| surface | `#FFFFFF` | 카드와 입력창 배경 |
| background | `#F6F7FB` | 페이지 배경 |
| danger | `#D93025` | 삭제 버튼, 오류 안내 |
| success | `#1E8E3E` | 완료 안내 |

- 글자와 배경의 명도 대비는 4.5:1 이상이다. primary 위의 글자는 `#FFFFFF`를 쓴다.
- 어두운 테마는 첫 버전에 넣지 않는다.

<br>

### 2. 글꼴

| 항목 | 값 |
|---|---|
| 본문 글꼴 | Pretendard. 불러오지 못하면 시스템 산세리프 글꼴 |
| 코드 글꼴 | 시스템 고정폭 글꼴 |
| 본문 크기 | 16px, 줄 높이 1.6 |
| 제목 크기 | 페이지 제목 28px, 절 제목 20px, 카드 제목 18px |
| 보조 글자 크기 | 14px |

<br>

### 3. 간격과 크기

| 항목 | 값 |
|---|---|
| 간격 단위 | 4px의 배수(4, 8, 12, 16, 24, 32, 48) |
| 본문 최대 너비 | 960px, 가운데 정렬 |
| 모서리 둥글기 | 버튼과 입력창 8px, 카드 12px |
| 반응형 기준 | 768px 미만은 모바일 배치 |

<br>

### 4. 공용 컴포넌트

기능마다 따로 만들지 않고 아래 컴포넌트를 같이 쓴다.

| 컴포넌트 | 쓰는 곳 |
|---|---|
| 버튼 | 기본(primary), 보조(테두리만), 위험(danger) 세 가지 |
| 입력창 | 한 줄 입력, 여러 줄 입력, 파일 선택 <br> 오류가 있으면 테두리를 danger로 바꾸고 아래에 사유를 보여 줌 |
| 목록 | 게시판 글 목록, 승인 대기 목록 <br> 페이지 이동 포함 |
| 카드 | 갤러리 앨범, 메인 화면의 최근 글과 앨범 |
| 안내 | 로그인 안내, 승인 대기 안내, 빈 목록, 오류 안내 |
| 확인 창 | 삭제, 탈퇴, 승인 거절처럼 되돌릴 수 없는 동작 전에 띄움 |

<br>

### 5. 공통 헤더와 메뉴

모든 화면 위에 같은 헤더를 둔다. 헤더 왼쪽에 로고와 메뉴, 오른쪽에 로그인 상태를 둔다.

| 메뉴 | 보이는 사람 |
|---|---|
| 소개 | 누구나 |
| 공지 | 누구나 |
| 갤러리 | 누구나 |
| 자유게시판 | 누구나. 들어가면 동아리원이 아닌 사람에게는 안내만 보임 |
| 자료게시판 | 누구나. 들어가면 동아리원이 아닌 사람에게는 안내만 보임 |
| 관리 | 운영진 |

| 로그인 상태 | 오른쪽에 보이는 것 |
|---|---|
| 로그인하지 않음 | 로그인, 가입 |
| 승인 대기 | 이름, 승인 대기 표시, 로그아웃 |
| 동아리원 | 이름, 내 정보, 로그아웃 |

- 로고를 누르면 메인 화면으로 간다.
- 모바일 배치에서는 메뉴를 접고 버튼으로 연다.
- 메뉴가 보인다고 권한이 있는 것은 아니다. 권한은 서버가 검사한다. ([시큐어 코딩 규칙](../security/secure-coding.md))
