# 게시판 배경

본 문서는 게시판 기능이 왜 필요한지와 범위를 정한다.

<br>

### 1. 왜 필요한가

게시판은 성격이 다른 세 가지로 나뉜다.

| 게시판 | 필요한 이유 | 보는 사람 |
|---|---|---|
| 공지 | 운영진이 동아리 소식을 동아리원과 외부 방문자에게 알리는 창구 | 누구나 |
| 자유게시판 | 동아리원끼리 소통하는 공간 | 동아리원 |
| 자료게시판 | 스터디와 활동 자료를 파일로 공유하는 공간 | 동아리원 |

자유게시판과 자료게시판은 동아리 내부 공간이라 동아리원만 본다. 공지는 외부에도 알려야 하므로 로그인하지 않아도 본다.

<br>

### 2. 범위

- 공지, 자유게시판, 자료게시판의 글 작성, 조회, 수정, 삭제
- 자료게시판 글의 첨부파일 업로드와 다운로드
- 글 본문은 일반 텍스트다. 마크다운 에디터는 MVP에 넣지 않는다. ([PRODUCT.md](../PRODUCT.md))

<br>
