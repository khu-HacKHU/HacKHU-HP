# 게시판 사용자 스토리

본 문서는 게시판마다 누가 무엇을 할 수 있는지와 완료 조건을 정한다.

역할의 정의는 제품 명세를 따른다. ([PRODUCT.md](../PRODUCT.md))

<br>

### 1. 공통

| 게시판 | 목록과 글 보기 | 글쓰기 | 수정과 삭제 |
|---|---|---|---|
| 공지 | 누구나 | 운영진 | 작성자와 관리자 |
| 자유게시판 | 동아리원 | 동아리원 | 작성자와 관리자 |
| 자료게시판 | 동아리원 | 동아리원 | 작성자와 관리자 |

- 글은 제목과 본문으로 이루어진다. 제목과 본문의 길이 제한은 게시판팀이 정한다.
- 본문은 글자만 쓴다. 굵게, 링크 같은 꾸밈은 없고 줄바꿈은 쓴 그대로 보인다.
- 목록은 최신 글이 먼저 오고 한 페이지에 20개씩 보인다.

| 상황 | 기대 |
|---|---|
| 권한이 없는 사람이 게시판을 봄 | 글쓰기, 수정, 삭제 버튼이 보이지 않음 <br> 주소를 직접 입력하는 등 다른 방법으로 시도해도 막힘 |
| 다른 사람이 쓴 글을 고치거나 지우려 함 | 관리자가 아니면 할 수 없음 |

<br>

### 2. 공지

운영진은 동아리 소식을 공지로 올리고, 누구나 공지를 본다.

| 상황 | 기대 |
|---|---|
| 로그인하지 않은 방문자가 공지 목록을 엶 | 공지 목록과 글을 볼 수 있음 |
| 운영진이 아닌 동아리원이 공지를 쓰려 함 | 쓸 수 없음 |
| 운영진이 다른 사람의 공지를 고치려 함 | 관리자가 아니면 고칠 수 없음 |

<br>

### 3. 자유게시판

동아리원은 자유게시판에 글을 쓰고 읽는다.

| 상황 | 기대 |
|---|---|
| 로그인하지 않은 방문자가 자유게시판을 엶 | 로그인 안내가 보이고 글 목록과 내용은 보이지 않음 |
| 승인 대기 회원이 자유게시판을 엶 | 승인을 기다린다는 안내가 보이고 글 목록과 내용은 보이지 않음 |
| 동아리원이 아닌 사람이 글 주소를 직접 엶 | 글 내용이 보이지 않음 |

<br>

### 4. 자료게시판

동아리원은 자료게시판에 파일을 첨부해 자료를 공유하고 받는다.

| 항목 | 값 |
|---|---|
| 허용 형식 | pdf, docx, pptx, xlsx |
| 파일 하나의 최대 크기 | 20MB |
| 글 하나의 최대 첨부 수 | 5개 |
| 첨부하고 받는 사람 | 동아리원 |

| 상황 | 기대 |
|---|---|
| 허용하지 않는 형식을 첨부함 | 올라가지 않고 허용 형식이 안내됨 |
| 20MB를 넘는 파일을 첨부함 | 올라가지 않고 크기 제한이 안내됨 |
| 6번째 파일을 첨부하려 함 | 올라가지 않음 |
| 동아리원이 아닌 사람이 첨부파일 주소를 알아냄 | 파일을 받을 수 없음 |
| 로그인하지 않은 방문자나 승인 대기 회원이 자료게시판을 엶 | 자유게시판과 같이 안내만 보임 |
