# 게시판 사용자 스토리

본 문서는 게시판마다 누가 무엇을 할 수 있는지와 완료 조건을 정한다.

역할의 정의는 제품 명세를 따른다. ([PRODUCT.md](../PRODUCT.md))

<br>

### 1. 공통

| 게시판 | 목록과 글 보기 | 글쓰기 | 수정과 삭제 |
|---|---|---|---|
| 공지 | 누구나 | STAFF 이상 | 작성자 또는 ADMIN |
| 자유게시판 | MEMBER 이상 | MEMBER 이상 | 작성자 또는 ADMIN |
| 자료게시판 | MEMBER 이상 | MEMBER 이상 | 작성자 또는 ADMIN |

- 글은 제목과 본문으로 이루어진다. 제목과 본문의 길이 제한은 게시판팀이 정한다. ([5-1 보안](backend/5-1-QUALITY-SECURITY.md))
- 본문은 일반 텍스트이고 줄바꿈을 유지한다. <!-- 검토: Claude 추가. 에디터가 MVP 밖이라서 -->
- 목록은 최신 글이 먼저 오고, 한 페이지에 보이는 글 수는 API 공통 규약의 기본값을 따른다. ([API 규약](../../conventions/api.md))

| 상황 | 기대 |
|---|---|
| 권한이 없는 사람에게 | 글쓰기, 수정, 삭제 버튼이 보이지 않음 <br> 버튼 없이 직접 요청해도 거부됨 |
| 다른 사람이 쓴 글 | ADMIN이 아니면 수정하거나 삭제할 수 없음 |

<br>

### 2. 공지

운영진은 동아리 소식을 공지로 올리고, 누구나 공지를 본다.

| 상황 | 기대 |
|---|---|
| 로그인하지 않은 방문자가 공지 목록을 엶 | 공지 목록과 글을 볼 수 있음 |
| MEMBER가 공지를 쓰려 함 | 쓸 수 없음 |
| STAFF가 다른 STAFF의 공지를 고치려 함 | 고칠 수 없음 |

<br>

### 3. 자유게시판

동아리원은 자유게시판에 글을 쓰고 읽는다.

| 상황 | 기대 |
|---|---|
| 로그인하지 않은 방문자가 자유게시판을 엶 | 로그인 안내가 보이고 글 목록과 내용은 보이지 않음 |
| 승인 대기 계정이 자유게시판을 엶 | 승인 대기 안내가 보이고 글 목록과 내용은 보이지 않음 |
| 동아리원이 아닌 사람이 글 주소를 직접 엶 | 글 내용이 보이지 않음 |

<br>

### 4. 자료게시판

동아리원은 자료게시판에 파일을 첨부해 자료를 공유하고 받는다.

| 항목 | 값 |
|---|---|
| 허용 형식 | pdf, docx, pptx, xlsx |
| 파일 하나의 최대 크기 | 20MB |
| 글 하나의 최대 첨부 수 | 5개 |
| 첨부와 다운로드 | MEMBER 이상 |

| 상황 | 기대 |
|---|---|
| 허용하지 않는 형식을 첨부함 | 올라가지 않고 허용 형식이 안내됨 |
| 20MB를 넘는 파일을 첨부함 | 올라가지 않고 크기 제한이 안내됨 |
| 6번째 파일을 첨부하려 함 | 올라가지 않음 |
| 동아리원이 아닌 사람이 첨부파일 주소를 알아냄 | 파일을 받을 수 없음 |
| 로그인하지 않은 방문자나 승인 대기 계정이 자료게시판을 엶 | 자유게시판과 같이 안내만 보임 |

파일을 주고받는 방식은 공통 규칙을 따른다. ([시큐어 코딩 규칙](../../security/secure-coding.md))
