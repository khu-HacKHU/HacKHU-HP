# 인증권한 사용자 스토리

본 문서는 가입부터 역할 변경까지 누가 무엇을 할 수 있는지와 완료 조건을 정한다.

역할의 정의는 제품 명세를 따른다. ([PRODUCT.md](../PRODUCT.md))

<br>

### 1. 가입

방문자는 이메일, 비밀번호, 이름으로 가입한다. 이름은 운영진이 승인할 때 누구인지 확인하는 데 쓰므로 실명을 적는다. 학번은 받지 않는다. 가입하면 운영진의 승인을 기다리는 승인 대기 회원이 된다.

| 상황 | 기대 |
|---|---|
| 필수 항목을 비워 둠 | 가입되지 않고 비어 있는 항목이 표시됨 |
| 이미 가입된 이메일로 가입하려 함 | 가입되지 않음 |
| 가입을 마침 | 승인을 기다린다는 안내가 보임 |

비밀번호의 길이와 조합 규칙은 인증권한팀이 정한다.

<br>

### 2. 로그인과 로그아웃

가입한 사람은 이메일과 비밀번호로 로그인하고 로그아웃한다. 승인을 기다리는 중에도 로그인은 된다.

| 상황 | 기대 |
|---|---|
| 이메일이나 비밀번호가 틀림 | 로그인되지 않음 <br> 둘 중 어느 쪽이 틀렸는지 알려 주지 않음 |
| 승인 대기 회원이 로그인함 | 승인을 기다린다는 안내가 보임 <br> 로그아웃과 내 정보를 빼면 로그인하지 않은 방문자가 할 수 있는 일만 할 수 있음 |
| 로그아웃함 | 다시 로그인하기 전까지 동아리원 기능을 쓸 수 없음 |

<br>

### 3. 가입 승인

운영진은 승인 대기 회원 목록을 보고 가입을 승인하거나 거절한다.

| 상황 | 기대 |
|---|---|
| 승인함 | 그 사람이 동아리원이 됨 |
| 거절함 | 계정이 삭제됨 <br> 같은 이메일로 다시 가입할 수 있음 |
| 운영진이 아닌 사람이 승인 대기 회원 목록을 열려 함 | 목록을 볼 수 없고 승인과 거절을 할 수 없음 |

<br>

### 4. 역할 변경

관리자는 동아리원의 역할을 동아리원, 운영진, 관리자 중에서 바꾼다.

| 상황 | 기대 |
|---|---|
| 관리자가 아닌 사람이 역할을 바꾸려 함 | 바뀌지 않음 |
| 관리자가 한 명만 남았고 그 사람의 역할을 내리려 함 | 바뀌지 않음 |
| 역할이 바뀜 | 바뀐 역할의 권한이 바로 적용됨 |

<br>

### 5. 내 정보

로그인한 사람은 자기 이메일, 이름, 역할을 보고 비밀번호를 바꾸거나 탈퇴한다.

| 상황 | 기대 |
|---|---|
| 비밀번호를 바꿈 | 현재 비밀번호를 다시 입력해야 바뀜 |
| 탈퇴함 | 계정이 삭제되고 그 계정으로 로그인할 수 없음 |
| 마지막 남은 관리자가 탈퇴하려 함 | 탈퇴되지 않음 |

탈퇴한 사람이 쓴 글과 앨범은 남긴다. 이메일과 이름은 지우고 작성자는 "탈퇴한 회원"으로 표시한다.

<br>

### 6. 비밀번호 초기화

비밀번호를 잊은 사람은 홈페이지 밖에서 운영진에게 요청한다. 운영진은 그 사람에게 임시 비밀번호를 발급한다. 메일을 보내지 않으므로 운영진이 임시 비밀번호를 직접 전달한다.

운영진은 자기보다 낮은 역할인 사람의 비밀번호만 초기화할 수 있다. 관리자는 모든 사람의 비밀번호를 초기화할 수 있다. 임시 비밀번호를 아는 사람이 그 계정으로 로그인해 다른 사람 행세를 하지 못하게 하려는 것이다.

| 항목 | 값 |
|---|---|
| 임시 비밀번호의 유효 시간 | 발급 뒤 24시간 |
| 임시 비밀번호로 로그인할 수 있는 횟수 | 1번 |

| 상황 | 기대 |
|---|---|
| 임시 비밀번호로 로그인함 | 비밀번호를 바꾸기 전에는 다른 기능을 쓸 수 없음 |
| 같은 임시 비밀번호로 다시 로그인하려 함 | 로그인되지 않음 |
| 발급 뒤 24시간이 지난 임시 비밀번호로 로그인하려 함 | 로그인되지 않음 |
| 운영진이 다른 운영진이나 관리자의 비밀번호를 초기화하려 함 | 초기화되지 않음 |
| 운영진이 아닌 사람이 비밀번호를 초기화하려 함 | 초기화되지 않음 |
