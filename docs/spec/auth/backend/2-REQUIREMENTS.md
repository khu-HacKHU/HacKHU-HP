# 2 요구사항

본 문서는 프론트엔드와 다른 기능이 인증권한 백엔드에 기대하는 것을 측정할 수 있는 값으로 정한다.

<br>

### 2-1. 로그인 유지

| 항목 | 값 |
|---|---|
| access 토큰 수명 | 15분 |
| refresh 토큰 수명 | 마지막 갱신부터 14일 <br> 갱신할 때마다 새로 14일이 시작됨 |
| 로그인 묶음의 최대 수명 | 로그인부터 30일 <br> 계속 써도 30일이 지나면 다시 로그인함 |
| 직전 refresh 토큰을 받아 주는 시간 | 회전한 뒤 10초 |

- access 토큰이 만료되어도 사용자는 로그아웃되지 않는다. 프론트엔드는 `401`과 `TOKEN_EXPIRED` 코드를 받으면 refresh API로 새 access 토큰을 받고 실패한 요청을 한 번 다시 보낸다. ([4-2-INTERACTION-CONTRACT.md](4-2-INTERACTION-CONTRACT.md))
- 프론트엔드는 동시에 여러 요청이 만료되어도 refresh API를 한 번만 부르고, 나머지 요청은 그 결과를 기다린다. 여러 탭이 동시에 부르는 경우는 백엔드가 직전 토큰을 10초 동안 받아 주는 것으로 흡수한다.
- 의도한 로그아웃만 일어난다. 직접 로그아웃, 비밀번호 변경, 비밀번호 초기화, 탈퇴, refresh 토큰 만료, 로그인 묶음의 최대 수명 도달이다.

<br>

### 2-2. 권한 반영 시점

| 변경 | 반영 시점 |
|---|---|
| 가입 승인 | 다음 요청부터 |
| 역할 변경 | 다음 요청부터 <br> 다시 로그인하지 않아도 됨 (USER-STORIES.md 4절) |
| 탈퇴 | 다음 요청부터 그 계정의 모든 토큰이 거부됨 |
| 비밀번호 변경, 초기화 | 다음 요청부터 그 전에 발급한 모든 토큰이 거부됨 |

이를 위해 인증할 때마다 토큰의 사용자 ID로 DB에서 계정을 읽는다. 토큰에 역할을 넣어 두고 믿지 않는다. ([DECISIONS.md](DECISIONS.md))

<br>

### 2-3. 응답 시간

| API | 목표 (p95) |
|---|---|
| 가입, 로그인, 비밀번호 변경 | 1초 이하 <br> 비밀번호 해시 계산에 약 0.3초를 씀 |
| refresh, 로그아웃 | 300ms 이하 |
| 그 밖의 인증권한 API | 300ms 이하 |
| 다른 기능 API에 더해지는 인증 처리 | 20ms 이하 <br> 토큰 서명 검증과 기본 키로 계정 1건 조회 |

동아리 규모(가입자 수백 명, 동시 접속 수십 명)를 가정한다. 별도 성능 테스트는 두지 않는다.

<br>

### 2-4. 처리량과 요청 제한

동시 사용자가 적어 처리량 목표는 두지 않는다. 대신 로그인과 가입에 요청 횟수 제한을 둔다. 값과 기준은 보안 문서에서 정한다. ([5-1-QUALITY-SECURITY.md](5-1-QUALITY-SECURITY.md))

학교 와이파이처럼 여러 사람이 공인 IP 하나를 함께 쓰는 환경에서 정상 사용자가 막히지 않아야 한다. 동아리 모집 날 한자리에서 50명이 가입해도 막히지 않는 값으로 잡는다.

<br>

### 2-5. 보존 기간과 데이터 수명

| 데이터 | 수명 |
|---|---|
| 활성 계정 | 탈퇴하거나 거절될 때까지 |
| 승인 대기 계정 | 운영진이 승인하거나 거절할 때까지 <br> 자동으로 지우지 않음 |
| 거절된 계정 | 거절 즉시 행을 지움 |
| 탈퇴한 계정 | 탈퇴 즉시 익명화하고 행은 남김 <br> 다른 기능의 글과 앨범이 이 행을 참조함 |
| refresh 토큰 기록 | 만료되거나 폐기된 뒤 1일이 지나면 지움 |
| 임시 비밀번호 | 발급 뒤 24시간, 로그인 1번 (USER-STORIES.md 6절) |

<br>

### 2-6. 배포 전제

refresh 토큰을 `SameSite=Strict` 쿠키로 주고받으므로, 프론트엔드와 API가 같은 사이트(같은 등록 도메인)에서 제공되어야 한다. 예를 들어 `hackhu.example`과 `api.hackhu.example`은 되고, 서로 다른 도메인은 안 된다. 실제 도메인 구성은 미확인이고 배포 문서에서 정한다. ([DEPLOYMENT.md](../../DEPLOYMENT.md))
