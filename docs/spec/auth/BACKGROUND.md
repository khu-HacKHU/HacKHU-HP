# 인증권한 배경

본 문서는 인증권한 기능이 왜 필요한지와 범위를 정한다.

<br>

### 1. 왜 필요한가

홈페이지 기능 대부분은 이용자가 누구이고 어떤 역할인지에 따라 동작이 달라진다. 자유게시판과 자료게시판은 동아리원만 보고, 공지는 운영진만 쓴다. 인증권한 기능은 가입한 사람이 누구인지 확인하고 역할을 붙여, 다른 기능이 권한을 판단할 근거를 준다.

동아리 홈페이지라서 가입했다고 바로 동아리원이 되면 안 된다. 그래서 가입과 동아리원 자격을 나누고, 운영진이 승인해야 동아리원이 된다.

<br>

### 2. 범위

- 이메일과 비밀번호로 가입, 로그인과 로그아웃
- 가입 승인과 거절
- 역할 변경
- 내 정보 조회, 비밀번호 변경, 탈퇴
- 운영진이 발급하는 임시 비밀번호로 비밀번호 초기화
- 다른 기능이 현재 사용자와 역할을 확인하는 방법 제공. 인가 검사는 각 기능이 직접 한다. ([PRODUCT.md](../PRODUCT.md))

<br>

### 3. 범위 밖

- Google 로그인은 MVP에 넣지 않는다. GitHub 로그인은 하지 않는다.
- 메일을 보내지 않는다. 학교 이메일 인증과 비밀번호 재설정 메일이 없다.
- 이유는 제품 명세의 하지 않는 것에 있다. ([PRODUCT.md](../PRODUCT.md))
